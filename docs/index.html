omnifin.

Unified Jellyfin user management.

Invites, account lifecycle, password resets and multi-channel notifications for your Jellyfin server, packaged into a single self-hosted binary. A hard fork of jfa-go, extended with live Jellyfin data in announcements and homelab-focused features.

View on GitHub Quickstart

Features

Invite system

Create expiring invite links, let users sign themselves up, apply profiles automatically.

Live announcement variables

Emails can embed poster grids of recent movies and shows, featured-title cards, top genres and user counts, filled from Jellyfin at send time.

Watch analytics

Jellystat-backed variables: most-watched titles, top watchers, plays and hours for the last 30 days.

Smart user selection

Select inactive or soon-expiring users with one click, then act on all of them at once.

Full account lifecycle

Expiry, disabling, deletion, password resets and contact preferences in one admin panel.

Drop-in for jfa-go

Migrates from an existing jfa-go setup. Ships as multi-arch Docker images.
